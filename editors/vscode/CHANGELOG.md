# Changelog

## 0.1.0, preview, 2026-11-11

First Marketplace release.

- Syntax highlighting, bracket matching and line comments for `.mam` files.
- **Mammoth: Run Mammoth File**, also on the editor's play button, and **Mammoth: Check Java Bindings**.
- Compiler errors appear in the Problems panel.
- Finds the compiler in `mammoth.compilerPath`, the workspace's `target/release`, the Windows setup's install folder, then `PATH`.
